# Catálogo de skills

Este repositorio reúne 24 skills para crear interfaces y experiencias web, y para apoyar tareas de documentación, análisis de datos y selección de modelos. Cada skill contiene instrucciones y, en muchos casos, una plantilla de referencia para orientar la generación de una solución.

## Cómo aplicar un skill

1. Identifica el resultado que necesitas y elige el skill correspondiente en el catálogo.
2. Abre el archivo enlazado y úsalo como instrucciones para el asistente o como guía al desarrollar la solución.
3. Describe el objetivo, el público, el contenido y los datos reales que deben utilizarse. Indica también las restricciones técnicas o visuales relevantes.
4. Adapta la plantilla y las recomendaciones al proyecto: revisa accesibilidad, contenido, comportamiento en dispositivos, seguridad y conexión con los servicios reales.
5. Valida el resultado en el entorno de destino. Las plantillas visuales son una base de implementación y no sustituyen la integración con una API, base de datos o sistema de producción.

## Skills de interfaces y experiencias web

### 1. Dashboard ejecutivo

**Archivo:** [SKILL_01_dashboard_ejecutivo.md](./SKILL_01_dashboard_ejecutivo.md)
**Funcionalidad:** Propone un dashboard de gestión con navegación lateral, tarjetas KPI, métricas y detalles accesibles desde ventanas flotantes. Su enfoque visual es corporativo y oscuro.
**Cómo aplicarlo:** Úsalo para reportes gerenciales o seguimiento de indicadores. Proporciona los KPIs, sus valores, períodos, tendencias y filtros; especifica qué decisiones debería facilitar cada indicador.

### 2. Portal de noticias con tarjetas

**Archivo:** [SKILL_02_portal_noticias_cards.md](./SKILL_02_portal_noticias_cards.md)
**Funcionalidad:** Organiza noticias, comunicados o boletines en tarjetas tipo masonry, con filtros por categoría y lectura detallada en un popup.
**Cómo aplicarlo:** Indica las categorías, artículos, fechas, autores e imágenes disponibles. Es apropiado para intranets, newsletters y portales editoriales.

### 3. Academia y cursos con acordeones

**Archivo:** [SKILL_03_academia_acordeones.md](./SKILL_03_academia_acordeones.md)
**Funcionalidad:** Estructura cursos por módulos desplegables e incorpora progreso, logros y elementos de motivación para el aprendizaje.
**Cómo aplicarlo:** Entrega el temario, las lecciones, el orden, la duración y las reglas de progreso. Úsalo para academias digitales, formación interna y onboarding formativo.

### 4. Portfolio creativo con ventanas flotantes

**Archivo:** [SKILL_04_portfolio_flotante.md](./SKILL_04_portfolio_flotante.md)
**Funcionalidad:** Presenta proyectos en una galería con filtros, ventanas flotantes arrastrables y un estilo glassmorphism.
**Cómo aplicarlo:** Aporta proyectos, imágenes, descripciones, categorías y enlaces. Es útil para portfolios profesionales, showcases de productos y presentaciones de propuestas.

### 5. Centro de ayuda y preguntas frecuentes

**Archivo:** [SKILL_05_centro_ayuda_faq.md](./SKILL_05_centro_ayuda_faq.md)
**Funcionalidad:** Organiza preguntas frecuentes por categorías, con búsqueda, acordeones y valoración de utilidad.
**Cómo aplicarlo:** Proporciona preguntas y respuestas revisadas, categorías y términos de búsqueda frecuentes. Úsalo para autoservicio, soporte al cliente y wikis internas.

### 6. Tablero Kanban

**Archivo:** [SKILL_06_kanban_board.md](./SKILL_06_kanban_board.md)
**Funcionalidad:** Visualiza tareas por columnas y estados, con tarjetas, filtros y ventanas de detalle.
**Cómo aplicarlo:** Define columnas, tareas, responsables, fechas y etiquetas. Úsalo para prototipos o vistas de proyectos, sprints y flujos operativos; conecta persistencia y colaboración si se requiere uso real multiusuario.

### 7. Presentación interactiva tipo slides

**Archivo:** [SKILL_07_presentacion_slides.md](./SKILL_07_presentacion_slides.md)
**Funcionalidad:** Guía la creación de presentaciones HTML con navegación, transiciones, notas del presentador y controles de presentación.
**Cómo aplicarlo:** Entrega el objetivo, audiencia, narrativa y contenido de cada diapositiva. Es adecuada para presentaciones ejecutivas y storytelling de datos.

### 8. Galería multimedia con lightbox

**Archivo:** [SKILL_08_galeria_lightbox.md](./SKILL_08_galeria_lightbox.md)
**Funcionalidad:** Muestra contenido visual en una cuadrícula masonry con filtros y vista lightbox ampliada, incluyendo navegación.

## Skills de documentación y datos

### 21. Generador de manuales técnico-funcionales

**Archivo:** [SKILL_CrearManuales.md](./SKILL_CrearManuales.md)
**Funcionalidad:** Guía la elaboración de manuales técnicos y funcionales detallados sobre procesos ETL, compensaciones y rezagos, a partir de documentos, paquetes SSIS y reportes disponibles.
**Cómo aplicarlo:** Reúne y proporciona los artefactos fuente, define el alcance y valida que estén accesibles. Solicita un manual con arquitectura, flujo de datos, diccionario, análisis técnico, reglas de negocio y conclusiones respaldadas por la evidencia.

### 22. Diseño HTML y UX para documentación

**Archivo:** [SKILL_diseño_HTML_UX.md](./SKILL_diseño_HTML_UX.md)
**Funcionalidad:** Define una guía de diseño para portales divulgativos y educativos en HTML/CSS/JS, con navegación por pestañas, paneles y estilo minimalista.
**Cómo aplicarlo:** Úsalo cuando el objetivo sea presentar conocimiento de forma sobria y modular, no crear una página de venta. Proporciona los temas y contenidos, y adapta la paleta e interacciones a las necesidades del proyecto.

### 23. Optimizador de ETL y consultas

**Archivo:** [SKILL_OptimizadorETLs.md](./SKILL_OptimizadorETLs.md)
**Funcionalidad:** Orienta un diagnóstico de rendimiento y optimización de ETL en SQL Server y SSIS, analizando ejecuciones, cuellos de botella, consultas y flujos con la evidencia disponible.
**Cómo aplicarlo:** Proporciona paquetes SSIS, consultas y métricas de SSISDB pertinentes; describe la línea base y el comportamiento actual. Solicita hallazgos ligados a evidencia y valida cualquier cambio en un entorno seguro antes de llevarlo a producción.

### 24. Router de modelos de bajo costo

**Archivo:** [SKILL_uso_low-cost-model-router.md](./SKILL_uso_low-cost-model-router.md)
**Funcionalidad:** Recomienda modelos de Abacus.AI según modalidad, disponibilidad de créditos y costo, con preferencia por opciones económicas y uso de caché.
**Cómo aplicarlo:** Antes de seleccionar un modelo, indica la tarea, modalidad, límite de créditos y prioridad de costo. Comprueba en la fuente vigente los precios, nombres y disponibilidad que documenta el skill antes de tomar decisiones de gasto.

## Recomendaciones de uso

- Selecciona el skill que más se aproxime al resultado; combina instrucciones solo cuando sus objetivos sean compatibles.
- Sustituye datos de ejemplo por contenido real y confirma las fuentes, derechos de uso y exactitud de la información.
- Considera las interacciones descritas como comportamiento a implementar: filtros, búsquedas, envíos, progreso y datos en vivo pueden requerir lógica o servicios adicionales.
- Revisa accesibilidad, navegación por teclado, diseño adaptable, privacidad y tratamiento de datos antes de publicar.
